# DYChatBot - 抖音私信自动回复机器人

DYChatBot 是一个抖音私信自动回复机器人，能够自动监控多个抖音商家后台账户的私信，对未读消息进行自动回复，并在出现异常时通过邮件通知管理员。它通过自动化监控、回复和异常通知功能，大幅提升客服效率。

## 功能特性

- 🤖 **多账户监控**: 支持同时监控多个抖音商家账户
- 💬 **自动回复**: 自动检测未读私信并发送预设回复
- 🛡️ **会话管理**: 自动处理登录和会话过期
- 📧 **异常通知**: 遇到问题时通过邮件实时通知
- 🔧 **灵活配置**: JSON 配置文件支持自定义参数
- 📊 **完整日志**: 详细的日志记录便于问题追踪
- 🔁 **重试机制**: 智能的重试策略提高稳定性

## 系统架构

系统分为以下核心模块：

1. **异常处理模块 (exceptions)** - 统一异常处理体系
2. **配置管理模块 (config)** - 加载验证 JSON 配置
3. **日志模块 (logger)** - 结构化日志记录
4. **认证模块 (auth)** - 抖音登录会话管理
5. **导航模块 (navigator)** - 页面元素交互
6. **监控模块 (monitor)** - 多账户消息监控
7. **机器人模块 (bot)** - 主程序编排
8. **通知模块 (notifier)** - 邮件异常通知

## 安装要求

- Python 3.10+
- Playwright (用于网页自动化)
- 依赖管理使用 uv

## 快速开始

1. 克隆项目并安装依赖：
   ```bash
   git clone <repository-url>
   cd DYChatBot
   uv sync
   playwright install
   ```

2. 配置文件设置：
   ```bash
   cp config.example.json config.json
   ```

   编辑 `config.json`，填入您的抖音账户信息和邮件配置。主要配置项包括：

   ### accounts (数组)
   包含需要监控的抖音商家账号信息：
   - `name`: 店铺名称（用于日志标识）
   - `username`: 登录用户名
   - `password`: 登录密码
   - `direct_url`: 商家后台直达链接

   ### monitor (对象)
   监控参数设置：
   - `user_list_size`: 用户列表显示大小
   - `poll_interval_seconds`: 轮询间隔秒数

   ### retry (对象)
   重试机制设置：
   - `login_max_retries`: 登录最大重试次数
   - `element_wait_timeout_seconds`: 元素等待超时秒数
   - `element_max_retries`: 元素操作最大重试次数

   ### email (对象)
   邮件通知设置：
   - `enabled`: 是否启用邮件通知 (true/false)
   - `smtp_host`: SMTP 服务器地址
   - `smtp_port`: SMTP 端口
   - `sender`: 发送者邮箱
   - `auth_code`: SMTP 授权码
   - `receivers`: 接收者邮箱列表

   ### logging (对象)
   日志设置：
   - `level`: 日志级别 (DEBUG, INFO, WARNING, ERROR)
   - `log_dir`: 日志存储目录

3. 启动机器人：
   ```bash
   python -m core.main config.json
   ```

   程序将自动加载配置、设置日志、初始化各模块并开始监控指定的抖音商家账户。

## 异常处理

系统采用层次化异常体系：
- `DYChatBotError` - 所有异常的基类
- `ConfigError` - 配置相关异常
- `AuthError` - 认证相关异常
  - `SessionExpiredError` - 会话过期异常
- `NavigationError` - 页面导航异常
- `NotificationError` - 通知发送异常

## 日志系统

日志同时输出到控制台和文件，默认日志目录为 `logs/`，按天轮转。

## 错误通知

当系统遇到错误（如认证失败、网络问题等）时，会通过邮件通知管理员。
